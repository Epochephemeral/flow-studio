# Flow Studio 验证记录

日期：2026-10-20。范围：独立项目的定义阅读、两条复杂示例、运行实例阅读和只读采集边界。

## 页面实际操作

使用生产构建，通过本地 HTTP 预览，实际执行以下操作：

| 检查 | 观察结果 |
| --- | --- |
| 从定义进入运行实例 | 页首有明确入口；显示所属 Flow 的实例、演示标记、总体状态和节点记录 |
| 内容实例 | 显示 6 个原生 run、15 条记录；跨 run 集合不冒充单个宿主 run |
| ASR 重试 | 同一 task 的尝试 1 失败与尝试 2 成功分别展示，保留各自证据和输出 |
| 输入输出 | 展示已提供的 JSON 值；未取得的值显示未采集，时间与配置不补成零值或默认值 |
| Insight 空结果 | 输出 insights=[]，状态为成功；其路由明确显示跳过及条件 |
| Claim 路由缺口 | 显示 unknown、Run ID 未知、结果和证据未提供，不推断成功 |
| 店铺实例 | 显示总体失败及确定项写入回执；目录写入节点成功与任务收尾失败分别保留 |
| 逐商品引用 | 商品 B 的补证、重判引用 B 的初判；任务收尾与目录汇总使用同一店铺范围 |
| 多流与单流切换 | 下拉框仅提供所选范围内的实例；不同实例不混用节点记录 |
| 切回定义 | 运行概览退出，URL 的实例参数移除；可再切回实例 |
| 刷新定位 | 实例、选中节点和运行详情从 URL 恢复 |
| 无选择与失效链接 | 空范围显示无实例；不存在的实例 ID 明确提示并要求重新选择，不默换为别的实例 |
| Prompt 与来源 | 静态 Prompt 全文、动态正文缺口、来源文件全文及行号仍可读取 |
| 图交互回归 | 内容流关系表显示 16 条关系；图可切纵向、聚焦，URL 保留方向与聚焦状态 |
| 窄窗口 | 在约 1000px 宽度检查详情抽屉、顶部实例选择和选中节点的可见区域 |
| 页面错误 | 本轮测试页读取的 error 级控制台记录为空 |

页面上的图仍表达定义依赖；节点记录说明一次实例里实际已知的发生情况。两者在运行模式的页尾明确区分。

## 自动检查

`npm run check` 执行 12 项测试并构建生产产物。覆盖：

- 两条复杂示例和通用入门示例可独立生成；实例真实进入网页快照。
- 重试历史保留、未知与无记录区分、Flow 范围筛选、无效实例 ID。
- 实例定义哈希不匹配时构建失败，保留已有发布快照。
- 店铺逐商品引用与汇总范围一致；终态需要证据，成功不能隐藏 unknown。
- 路径穿越、外部符号链接、来源缺失、错误哈希、残留来源文件处理。
- 采集计划只含显式只读命令，限定对象数，并禁止原始采集包写入产品仓库。
- 采集执行分支用本地替身 CLI 测试原始字节、哈希与失败清单；没有连接生产环境。

## 证据边界

当前两份实例是 synthetic，使用 example: 身份及演示输入输出。真实生产实例、活跃策略、完整模型请求和线上 attempt 历史未采集。本轮不能据此证明生产执行、商品判断质量或线上采集已通过。

定义校验检查结构和引用；不会验证任意宿主的调度语义、数据类型兼容性或每个证据引用的真实性。机器可读控制依赖、实时运行和执行调试不属于本轮已验证范围；当前表达边界见 [Node 与 Flow](concepts.md)。
